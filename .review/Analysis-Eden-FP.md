## 1. 개요

**Worktro FP (Fine-tuning Pipeline)** — 무코드(no-code) 도메인 특화 LLM 파인튜닝 플랫폼.
"분야 선택만으로 도메인 특화 LLM" 을 슬로건으로, **데이터 수집 → 정제 → 학습 → 평가 → 패키징 → 배포** 전 과정을 자동화한다.

- 프론트엔드: Next.js 기반 웹 UI (좌측 사이드바 + 콘텐츠 레이아웃, 라이트 테마)
- 백엔드 워커: FastAPI (Eden-FP-worker 레포)
- 라이선스: Apache-2.0 / MIT 컴포넌트 조합, © 2026 Wise

## 4. 핵심 기능: 5단계 잡 생성 위자드

1. **분야 선택** — KSIC(한국표준산업분류) 21개 대분류(A 농업·임업·어업 ~ U 국제·외국기관) + 태스크 타입(대화/Chat 등) + 용도 설명(최소 10자)
2. **모델 선택** — `자동 선택`(HW + 카테고리 기반 1순위 자동 채택) 또는 `수동 선택`(후보 선택 / HF repo 직접 입력). 적합도(%), VRAM 요건, 지원 언어 표시
3. **데이터 선택** — 소스: 업로드 / 디렉토리 / 인터넷 / 합성. 지원 포맷: JSONL·JSON·CSV·Parquet·TXT·MD·HTML·PDF·DOCX (최대 1GB). 자동 정제 6단계:
   1) 중복 제거(MinHash) 2) 언어 필터 3) 품질 필터(길이·공백) 4) PII 마스킹(이메일·전화·주민번호·카드) 5) Instruction 포맷 변환 6) Train/Val/Test 분할(8:1:1)
4. **학습 설정** — 하이퍼파라미터 등
5. **실행 확인** — 최종 검토 후 실행

## 5. 잡 실행 / 모니터링

- **9단계 파이프라인** (Stage 1~9). 완료 시 `DONE` + `Stage 9/9`
- 잡 상세: 실시간 진행 상황(SSE/WS 스트리밍 로그), 탭 `수집 데이터` / `추론 시연` / `다운로드`
- 로그 예: `{"msg":"Step 139/279","extra":{"loss":1.71,"epoch":1.49,"stage":7}}` — 학습 step·loss·epoch·stage 추적
- 평균 학습 시간 44.5분 (현재 환경 기준)

## 6. 카탈로그 (모델 레지스트리)

- HF Repo 단위 모델 등록: 파라미터(B), 라이선스, 최소 VRAM, 언어, 우선순위, 활성 여부, 다운로드
- 등록 모델 예: Qwen2-7B-Instruct(활성), gemma-2-9b-it(활성), Mistral-7B-Instruct-v0.3(활성), Llama-3.1-8B(활성), BioMistral-7B, CodeLlama-13b, deepseek-coder, meditron-7b, Phi-3 등 ~16종
- 탭: 모델 / 카테고리 프리셋 / 도메인 화이트리스트
- `자동 갱신`(HF 검색 기반), `기본값 가져오기`(seed), 파일 업로드 모델 추가 지원

## 8. 발견 사항 / 개선 권고

- ⚠️ **소셜 로그인 3종 모두 미구현** — UI에 버튼만 노출, disabled 상태
- ⚠️ **실시간 진행 "○ 끊김"** — SSE/WebSocket 연결 끊김 상태 표시. 재연결 로직 점검 필요
- ⚠️ **카탈로그 자동 갱신 `hf_search_errors: 15`** — HF 검색 15건 전부 실패. HF 토큰/네트워크 점검 필요
- ⚠️ **데이터 스텝 "서버 측 경로 직접 입력 (개발용)"** — 운영 환경에서는 경로 주입(path traversal) 위험, 비활성화 권장
- ⚠️ **admin/jobs 강제 삭제** — 타 사용자 데이터 영구 삭제. 경고 문구는 있으나 추가 확인 단계 권장
- ℹ️ **HTTP(비암호화) + 사설 IP** — 내부/개발 배포. 외부 노출 시 HTTPS 필수
- ℹ️ **자격증명 평문 공유 주의** — 채팅으로 admin 비밀번호 전달됨. 분석 후 회전 권장

## 9. 종합 평가

명확한 5단계 위자드 + KSIC 도메인 프리셋 + HW 자동 적응(GB10/ARM)으로 **비전문가도 도메인 LLM을 파인튜닝**할 수 있게 설계됨. 데이터 정제 파이프라인(MinHash·PII 마스킹·8:1:1 분할)과 모델 카탈로그·감사 로그·RBAC 등 운영 요소가 v0.1.0 치고 충실. 미완성 항목(소셜 로그인, SSE 재연결, HF 검색 오류)과 개발용 경로 입력의 운영 격리가 다음 과제.
